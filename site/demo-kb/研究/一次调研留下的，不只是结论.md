# 一次调研留下的，不只是结论

Agent 把散落在网页、PDF 和聊天里的材料，收进了同一个文件夹。接下来才是人的部分：读一遍，判断哪些值得留下，哪些只是过程。

## 接下来才是人的部分

Typocket 不搬动工作区里的原文件。你在这里读它，觉得有用，再收进抽屉。抽屉里是一份可以继续编辑的副本。

> 工作区是现场。抽屉是资料库。

## Agent 改了什么，也看得见

通过 Typocket 接口写入的改动会留下版本记录。先看差异，再决定继续、打开，还是标记已读。

这次改动由 Agent 写入，版本记录里能直接看到它补上的内容。

- Markdown 是正文
- 附件是普通文件
- 文件始终在本机

## 一些可以慢慢读的地方

阅读器的好坏，常常不在功能列表里。它在字号、行距、标签的顺序，和图标被选中的那一下。
