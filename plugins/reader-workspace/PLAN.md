# Reader 插件化实施计划

目标流程：在任意工作区提出整理要求，Agent 查找获授权的知识库，直接保存文档及图片，返回可打开的链接；Reader 网页和 DSH 看到同一份内容。项目文件留在原项目，导入知识库时明确生成副本。现阶段不做自动采集会话或双向同步。

## 第一阶段：本机试用

- [x] 保留独立的 `DOCS_ROOT`，插件只通过内容服务读写。
- [x] Agent 能列出获授权知识库，直接保存、搜索、读取及按版本修改。
- [x] 来源单独存放且不公开；备份、恢复及文档改名后仍能找回。
- [x] DSH bundle 格式与原有 MCP 适配器共用工具实现。
- [x] Reader 授权界面可一次选择多个知识库。
- [x] DSH 右侧栏开始页提供阅读器入口，并沿用 Reader 的 SVG 超椭圆底板；原生标签直接加载 Reader 网页。
- [x] 本地 DSH NEXT 桌面端已安装试用版；旧版入口及 Markdown 预览曾实际打开验证。
- [x] 在当前运行的 DSH 窗口验收阅读器入口与 Markdown 标签：工作区 README.md 打开为 Reader Markdown 预览，右侧标签显示文件名。
- [ ] 重载 DSH 插件后实测快捷键；当前宿主按键未成功触发，命令目标解析已按 DSH 内置实现修正。Markdown 标签图标也需目视复核。
- [x] 本机 Markdown 预览进入 Reader“工作区浏览记录”，按来源去重；可回看快照、归档恢复并收录为私有文档，收录后记录保留。
- [ ] 在真实 DSH profile 中安装并走完两个工作区的端到端操作。
- [ ] 验证 DSH 侧栏中的登录、粘贴图片、上传与导出；必要时做窄屏界面调整。

## 第二阶段：给别人安装

- [ ] Reader 服务、静态界面和插件做成可独立安装的一套交付物，并提供首次选择数据目录的流程。
- [ ] 将个人部署用的默认文档和旧书签映射移到实例配置；保留现有公网实例的旧链接。
- [ ] 在干净环境验证安装、升级、备份恢复和卸载后数据保留。
- [ ] 明确支持的 DSH 与 Node.js 版本，验证版本升级后的兼容性。
- [ ] 将侧栏入口地址做成可见的连接设置，并与工具使用的 Reader 服务地址保持一致。

## 后续单独推进

- 私人手机访问，同一台电脑在线时通过安全的私有网络连接。
- 工作区文件的实时引用及双向同步；先观察手动导入副本是否已经满足日常需求。


## 2026-10-01 本轮范围与验收

已实现：本地免登录、强制访客预览、访客权限提示、知识库栏底部入口、长文内嵌弹窗定位、网格收录与草稿、副本打开、统一排序菜单、上传图标历史、品牌图标、只读临时快照分享。

已验证：构建、权限隔离、旧公开路由、收录与资源、插件工具、快照不含私有文档和来源；浏览器实测长文收录弹窗可见并成功打开草稿副本，交付文档显示只读且不能编辑，示例文档显示可编辑；隔离的假文档和假隧道验证临时分享可开启、只读、手动更新和停止。

复核于 2026-10-01：DSH 已安装并启用插件；右侧“开始”页的阅读器入口恢复，点击后出现阅读器标签和“在浏览器打开”链接。本机 8090 页面可访问；从 DSH 文件区打开工作区 README.md，确实生成以文件名命名的 Reader Markdown 预览标签，收录弹窗在 DSH 内实际显示。当前运行的宿主中阅读器快捷键未成功触发，已修正命令目标解析，但需重载插件后复测；标签图标和真实公网隧道的外部连通性仍需实测。本轮没有推送或部署。

界面复核：知识库管理网格、排序和公开状态已在本机浏览器看到；收录、复制、移动改为可搜索的知识库网格，并在浏览器验证了选中草稿后才可确认。访客文档当前权限放在顶栏，文档列表不再逐行常驻权限图标；悬停名称可查看权限。搜索提示、分享面板和插入内容弹窗删去冗长说明；自定义图标与封面弹窗恢复轻描边。权限确认、分享和收录弹窗采用相同的轻量出入动效。构建、权限、旧公开路由、收录、插件及只读测试通过。全平台逐屏验收尚未完成。
