# 示例抽屉

这是这个文档工具的示例内容，用来展示它完整的样子。

它与正式的抽屉分开：这里只有演示材料，与任何真实资料互不影响。

## 里面有什么

| 文档 | 展示的能力 |
| --- | --- |
| [正文与排版](正文与排版.md) | 标题层级、段落节奏、加粗斜体、列表、引用、行内代码、脚注、上下标、任务清单 |
| [表格](表格.md) | 普通表格、列对齐、长单元格换行、窄容器里宽表自己横向滚动 |
| [代码与图表](代码与图表.md) | 多种语言的代码块、行内与块级公式、mermaid 流程图与时序图 |
| [长文](长文.md) | 多级标题构成的长文，右侧目录的层级、当前位置高亮与跳转 |
| [产品白皮书](产品白皮书.pdf) | PDF：按页阅读，右侧是 PDF 自带的书签目录 |
| [检索控制台](检索控制台.html) | H5：整页渲染，保留它自己的布局与交互 |

左侧的目录是嵌套的，点开子目录可以看到多层结构。
