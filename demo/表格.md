# 表格

## 普通表格

| 维度 | 看什么 | 权重 |
| --- | --- | --- |
| 信息组织 | 层级、归属、当前位置 | 15% |
| 文字与排版 | 标题比例、段距、强调 | 25% |
| 页面构图 | 区域比例、对齐、留白 | 15% |
| 视觉系统 | 字体、色彩、图标、圆角 | 15% |
| 操作与反馈 | 控件层级、状态、可发现性 | 15% |
| 多文档切换 | 标签、关闭、位置保持 | 15% |

## 列对齐

表头下面加冒号控制这一列怎么对齐：

| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| 文本靠左 | 文本居中 | 文本靠右 |
| 这一列通常最长 | 短标签 | 1,284 |
| 继续 | 继续 | 3,901 |

## 长单元格

| 情况 | 说明 |
| --- | --- |
| 字数很多的时候 | 文字在单元格内换行，行高自动撑开，不会把表格挤变形。列宽按内容比例分配，不会出现某一列被压成一条线。 |
| 中英混排 | 中文和 Latin 混在一起时，换行点由浏览器按字符类型决定，通常不会出现半个单词被切开。 |
