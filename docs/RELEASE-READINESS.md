# 正式版门槛与已知问题

`0.2.0-preview.1` 已作为 GitHub Preview 发布；主要本机工作流程、恢复闭环和实际安装包已验收。还不能据此宣称所有平台的 1.0 正式版可发布。现有交付服务器保持原样。

## 平台证据

| 平台/环境 | 本轮证据 | 仍需外部验收 |
| --- | --- | --- |
| macOS | 官方 DSH 安装器及 DSH NEXT 2.0.16-next 所带 Web 宿主，旧包升级、新包卸载重装、中文空格路径、固定端口和旧文档保留 | 两个原生 DSH 桌面窗口并行；完整原生应用冷启动体验 |
| Windows | 平台数据目录与 Explorer 分支、Node 24 CI 矩阵 | Windows DSH 真机安装、文件定位、升级与桌面行为 |
| Linux | XDG 路径、xdg-open 分支、Node 24 CI 矩阵 | 目标 DSH 宿主和桌面环境实测 |
| 窄屏 Web | 420px 实际 iframe 中搜索、收录、二级返回、正文检查 | 不等于 iOS DSH 插件支持，DSH 插件仍是桌面入口 |

发布提交 `e69e0d1` 的 macOS/Windows/Ubuntu Node 24 全套远程 CI 已通过。运行结果见 [验证记录](VERIFICATION-2026-10-04.md) 和 [最终审查](RELEASE-AUDIT-2026-10-04.md)。CI 不能证明 Finder/Explorer 或原生窗口交互。

## 已完成的闭环

- 工作区预览、收录独立副本、整理、检索、Agent 限范围再次读写；来源说明明确。
- 稳定服务地址、同库复用、连接离线提示、冲突拒绝；不静默换空库。
- Markdown 直接编辑，脚注、普通 HTML 文本和公式已有对应编辑结构；PDF 随包阅读器和 H5 隔离预览。
- 历史差异、当前修改保护、回收站新旧记录恢复、完整备份、恢复后打开独立副本。
- 实际 tgz 包解压后启动；无知识库数据库、密码、授权或个人交付内容；补齐字体/PDF 资产许可。
- 生产构建、类型边界、权限、旧公开路由、事务恢复、生命周期和完整工作流程回归。

## 已知限制与正式版优先门槛

1. **旧版第一次升级的阅读偏好**：preview.2 未持久化端口，首次升级可能变更浏览器 origin，使主题等站点偏好重置一次；原文和知识库设置保留。新版本后续重启与重装保持地址。
2. **跨平台原生宿主**：必须在 Windows/Linux 真实 DSH 环境验证后再作完整支持承诺。macOS 本轮使用官方安装链与 Web 宿主，不冒充全部原生桌面交互已测。
3. **外网分享**：依赖 cloudflared、网络与本机持续运行；真实外部设备端到端连通性尚未验收。本地地址不能当作外网交付链接。
4. **编辑范围**：已移除文档顶部的编辑模式切换。普通 HTML 文本、脚注和公式可编辑；其他原始内容块保留独立编辑入口。仍有往返校验无法通过的语法会回退文本编辑，不能承诺任意 Markdown 扩展都能无损富文本编辑。PDF 无批注/编辑；加密 PDF 提示外部打开；H5 不授予同源访问能力。
5. **备份边界**：本机同盘备份不是异地备份；跨机器导入仍使用命令。备份时外部编辑器直接写文件不受 Reader 锁控制，应暂停外部写入。
6. **性能与包体**：安装包约 60.67 MB；已做可复现本机基线，尚无低配机器和超大库证据，不作普遍性能承诺。

## 维护计划

保留 Vue/Vite/Node/SQLite，逐步扩展 TypeScript 的实际业务边界和旧大组件拆分，不为形式重写全工程。历史个人交付路由与产物等面试交付结束再清理。正式版与交付服务器更新继续独立评估。
