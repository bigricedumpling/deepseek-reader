## 本轮已验证

- 临时数据目录的真实服务启动、同库复用、停止、重启地址保持、端口冲突拒绝替代。
- 历史公开地址、公开内容过滤、父级权限、示例编辑、事务恢复、Agent 作用域、工作区收录。
- 隔离浏览器中历史版本预览与恢复保存，420px 窄视口弹窗、Esc 关闭与返回入口焦点。
- 实际 `.tgz` 解包后的服务生命周期测试通过；包内未发现知识库数据库、服务记录、管理密码或分享配置。
- 安装包约 59.9 MB，313 个文件；这次未做字体裁剪。
- 人工制造外部文件更新与本地编辑冲突，验证保留两份内容、确认后采用磁盘版本。
- 回收站恢复、同名冲突拒绝、默认私有、稳定标识和列宽保留、整库删除恢复；本机备份及独立目录恢复。
- 由旧版代码创建测试库，再由新代码打开与备份恢复，验证正文、稳定标识和页面设置保留；这不是完整 DSH 安装升级验收。
- 类型契约检查和生产构建。

## 正式版前优先处理

1. **恢复后的数据目录切换**：本轮已补回收站、完整备份及独立副本恢复界面；跨机器导入、旧回收记录原路径缺失、恢复后自动切库仍待完善。
2. **安装包级更新验收**：不能只跑源码和 mock 测试。用旧包创建数据，再安装新包验证正文、图片、页面设置、阅读偏好和授权。
3. **编辑无损范围**：复杂 Markdown 的源码保护仍较突兀；保留保护，继续改善阅读与源码切换，不能承诺所有语法都可无损富文本编辑。
4. **分享可达性**：临时公网链接依赖 cloudflared 和网络，真实外部设备验收尚未完成。本阶段不扩大协作能力。
5. **性能基线**：较大的字体和编辑器包仍存在，应测长文、冷启动和低配机器，再决定拆分，不凭包大小推断所有用户都会卡顿。

## 后续维护

逐步拆分大型导航与 API 模块；TypeScript 从契约与新增模块开始扩展。旧个人交付路由和历史部署产物暂时保留，待交付结束后再配置化清理。已有 public/demo 产物不能未经核对删除。

版本发布必须明确：本轮改了什么、验证过什么、仍有什么限制。暂不将本分支部署到正在使用的笔试题交付站点。
