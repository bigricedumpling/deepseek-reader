# 支持范围与已知问题

Reader 当前以 Preview 版本提供。安装包包含网页与本机服务，适合在 DSH 中阅读、编辑和整理个人资料。

## 平台

| 平台 | 当前支持情况 |
| --- | --- |
| macOS | 已使用 DSH NEXT 2.0.16-next 的官方安装链验证安装、启动、保存和重启；两个原生桌面窗口并行使用仍待验证 |
| Windows | 已实现数据目录和文件资源管理器适配，并通过 Node.js 自动检查；原生 DSH 安装、升级和文件定位仍待验证 |
| Linux | 已实现 XDG 目录和桌面打开适配，并通过 Node.js 自动检查；原生宿主体验仍待验证 |

窄屏网页可用于阅读，但不代表支持在 iOS 安装 DSH 插件。自动检查覆盖文件服务、权限、恢复和安装包运行，不替代原生桌面交互验证。

## 文档格式

Markdown 是主要编辑格式，支持常见正文、列表、表格、公式、脚注和简单 HTML 文本。部分扩展语法无法完整映射到富文本编辑器；无法安全还原时保留原文并使用文本编辑，不保证所有 Markdown 方言都能无损富文本编辑。

PDF 支持阅读，不提供编辑与批注；加密 PDF 需要在外部应用中打开。HTML 页面在隔离环境中预览，不具备完整网站的权限和运行环境。

## 数据与升级

- 从 `0.1.0-preview.2` 首次升级时，服务端口可能变化，浏览器主题等阅读偏好可能重置一次；正文和知识库设置保留。后续版本会复用保存的服务地址。
- 已连接的旧 Reader 离线时会显示连接错误，不会自动切换到新的空知识库。
- 工作区文件和收录副本各自独立，不提供双向同步。
- 本机同盘备份不能防止整块磁盘损坏。跨机器导入备份目前需要命令行，见 [数据与恢复](DATA-AND-RECOVERY.md)。
- 备份期间请暂停外部编辑器或 Agent 直接写入文件，外部写入不受 Reader 的备份锁控制。

## 分享与 Agent

Agent 工具需要授权指定知识库；安装插件不会自动授予访问权限。临时外网分享依赖 `cloudflared`、网络和本机持续运行，外部设备的完整访问流程仍待验证。

## 性能

安装包约 61 MB，包含 PDF 阅读组件与字体。目前没有低配设备和超大知识库的完整性能结论。

遇到问题可在 [GitHub Issues](https://github.com/bigricedumpling/deepseek-reader/issues) 提交系统版本、插件版本和复现步骤。涉及正文时请使用脱敏示例。
