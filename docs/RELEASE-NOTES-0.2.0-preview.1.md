# Reader 0.2.0 Preview 1

Reader 是 DSH 中的本地文档工作台。你可以直接查看 Agent 在工作区生成的 Markdown，把值得保留的内容收录为知识库副本，继续阅读、编辑、整理，再让 Agent 在授权范围内使用这些资料。正文留在本机普通文件中。PDF 和 H5 也可预览。

## 安装

在 DSH NEXT 的插件页面选择本页的 `dsh-reader-workspace-0.2.0-preview.1.tgz`，安装后从「开始 → 阅读器」进入。安装包自带 Reader 页面与本机服务，不需要另外部署 Reader 或安装 Node.js。首次使用会建立默认的「草稿」知识库，之后可以自行改名或删除。

本次安装及重启已在 macOS 上使用 DSH NEXT 2.0.16-next 自带的官方安装器与独立配置验证。Windows、Linux 的路径和运行分支已纳入代码及 CI；各自的原生桌面安装和文件定位仍需真机验收。

## 本版变化

- 工作区浏览记录与知识库阅读历史分开。记录可隐藏、筛选找回和收录为独立副本；原工作区文件不会被移动。
- 保持本机 Reader 地址，旧服务离线时明确提示，避免静默切换到另一份空库。首次从旧 Preview 升级可能让浏览器阅读偏好重置一次，正文不会因此丢失。
- Markdown 正文、脚注、普通 HTML 文本及公式的编辑能力已增强；仍使用往返检查保护未覆盖的语法。
- 多标签、右键菜单、紧凑插入菜单及浮层交互重新整理。标签仅在文档设置过图标时显示图标，并减少重复提示。
- 文档历史、误删恢复与完整备份可用；备份恢复到独立副本，不覆盖原库。
- PDF 使用随包阅读器；H5 在隔离页面预览。

## 已知限制

- Agent 直接检索或修改知识库需要另行授权指定范围；插件安装不自动授予资料访问权限。
- 临时外网分享依赖网络与隧道服务，真实外部设备的端到端连接尚未验收。
- 尚未承诺所有 Markdown 扩展都能无损富文本编辑；不能安全往返的内容会保护原文并回退文本编辑。
- Windows/Linux 原生 DSH 桌面及两个原生窗口并行仍需实测。iOS 不属于 DSH 插件安装平台。
