# Typocket 0.2.0 Preview 5

此版本修正了平台支持说明，程序功能与 Preview 4 相同。Typocket 是 DSH 桌面端的 Preview 版本，不限于 macOS。安装包在 macOS、Windows 和 Linux 的自动检查中均已通过；原生 DSH 安装、启动和阅读器入口目前在 macOS 完成验收，Windows 与 Linux 的原生桌面体验仍待验收。

从 [发布页](https://github.com/bigricedumpling/deepseek-reader/releases/tag/v0.2.0-preview.5)下载 `dsh-reader-workspace-0.2.0-preview.5.tgz`，在 DSH NEXT 的「插件 → 添加插件」中安装，再从「开始 → Typocket」进入。平台与功能边界见[支持范围与已知问题](RELEASE-READINESS.md)。
