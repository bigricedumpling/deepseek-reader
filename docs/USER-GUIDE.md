# 从工作区到自己的抽屉

Typocket 是给个人使用的本地文档工具。Agent 负责生成和处理文件，你负责阅读、判断、修改和整理；正文以普通文件留在本机，之后还能交给 Agent 继续工作。

## 第一次打开

在 DSH 安装插件后，进入「开始 → Typocket」。安装包包含页面和本机服务，无需另装 Typocket。首次打开创建本机抽屉；再次打开沿用自己的资料。安装步骤见 [README](../README.md)。

## 查看工作成果

在 DSH 打开工作区 Markdown，使用 Typocket 预览。工作区浏览记录保存曾打开的工作区文件，不混入抽屉的阅读历史。记录是预览快照，原文件仍在原项目目录；再次打开原文件可以更新预览。需要定位原件时使用「在访达中显示」；Windows 对应文件资源管理器，具体宿主支持见 [平台说明](RELEASE-READINESS.md)。

想长期保留一份：打开记录，选择「收录副本」，选择抽屉和文件夹。收录不会移动或修改原文件。之后编辑的是抽屉副本，原文件与副本不会自动同步。文档菜单中的「文档信息」可查看来源、保存位置和两者关系。

浏览记录默认显示「最近浏览」。详情中的「隐藏记录」只隐藏这条记录，不移动或删除原文件；在筛选中选择「已隐藏」，可以重新「恢复显示」。

## 写作和整理

Markdown 支持直接写作、文件夹整理、搜索和多文档标签。脚注和普通 HTML 文本直接在正文中编辑；公式和其他独立内容块通过对应编辑框修改。仅打开文档不会自动改写原文件。未覆盖的扩展语法及保护性回退见 [编辑范围](RELEASE-READINESS.md)。

侧栏空白处右键可刷新文件列表，也可进入批量删除。选中文件夹时会包含其中的文档；确认后所选内容进入回收站。

阅读排版可以调整字体、字号、宽度、行距和主题。PDF 使用独立的分页阅读器；H5 在隔离页面中预览，适合查看 Agent 生成的页面成果。PDF 不提供编辑与批注，H5 预览不等于完整网站运行环境。

## 找回修改和误删内容

文档菜单中的「历史版本」可以预览旧稿、对比差异，再决定是否恢复。恢复前会保存当前修改；如果外部编辑器或 Agent 同时改了文件，会先进入冲突处理，不直接覆盖另一份内容。

在侧栏底部「更多工具」中打开「回收站」或「备份与恢复」。旧回收文件如果缺少原路径，可以选择恢复位置。完整备份恢复成独立副本，点击「打开恢复副本」核对；页面会标明恢复副本，原库保持不变。详见 [数据与恢复](DATA-AND-RECOVERY.md)。

## 让 Agent 继续使用资料

阅读器安装后就能用。只有需要 Agent 直接检索或修改抽屉时，才在「Agent 访问」中授权指定范围。工具会检查文件版本，避免把人的新修改静默覆盖。令牌属于本机授权，不应粘贴进文档或公开仓库。

## 给别人看

临时分享生成只读副本，后续编辑不会自动发布，需主动更新快照。外网链接依赖隧道服务和网络；未具备条件时可以导出文件交付。本机管理无需账号，当前不提供多人实时协作。既有服务器的可编辑示例库是部署者配置的演示能力。

## 阅读与文档操作

右上角「文档操作」（三个点）提供文档信息、历史版本、原文件位置和导出；PDF 与 H5 提供打开原文件。PDF 有独立的页码和缩放控件。

「纳入分享范围」只决定内容能否进入访客视角和分享副本，不会生成链接。抽屉管理中的「分享只读副本」会先列出本次范围；原稿更新后需主动更新副本。未纳入范围的文档不显示访客编辑权限。

排版与界面外观是当前浏览器的阅读偏好；文档图标、封面与页面布局随文档保存。触屏点击不显示悬停提示，鼠标悬停与键盘聚焦图标仍可查看提示。

## 编辑复杂文档

正文、表格、脚注和普通 HTML 文本可以直接编辑。点击公式可修改公式代码并即时预览，保存后更新正文。文档属性独立编辑。

回收站可以按名称或原路径搜索，恢复后返回原位置。完整备份恢复为独立副本，在对应记录右侧打开。

首次安装会添加草稿抽屉，可重命名或删除；删除后不会自动重建。侧栏更多工具分别提供回收站、备份与恢复入口。

## 主题色

在侧栏底部「更多工具 → 设置」中选择主题色。新安装默认使用石墨，也可选择蓝色、松绿、紫色或陶土。选择后立即生效，并保存在当前浏览器中。浅色、深色和护眼外观仍从右上角「外观」切换。

同一处可以选择界面字体。「默认」沿用微信体及系统回退，另有衬线、无衬线、鸿蒙黑体、楷体和苹方。界面字体与正文的排版设置独立。
