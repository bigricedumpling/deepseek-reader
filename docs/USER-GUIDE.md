# 从工作区保存文档

Typocket 是给个人使用的本地文档工具。Agent 负责生成和处理文件，你负责阅读、判断、修改和整理；正文以普通文件留在本机，之后还能交给 Agent 继续工作。

## 第一次打开

在 DSH 安装插件后，进入「开始 → Typocket」。安装包包含页面和本机服务，无需另装 Typocket。首次打开会创建「草稿」知识库。第一篇可以直接在这里新建，也可以在 DSH 文件区打开 Agent 生成的 Markdown，点「保存到知识库」。此后可以按项目新建知识库，在里面用文件夹整理文档。安装步骤见 [README](../README.md)。

## 查看工作成果

在 DSH 打开工作区 Markdown，使用 Typocket 预览。预览只读，不会移动原文件；相对图片从当前工作区读取。关闭预览后不在 Typocket 留下浏览记录，需要再次阅读时从 DSH 的文件树重新打开。

想长期保留一份：在预览页点「保存到知识库」，选好位置并确认文档名称。副本会放在该知识库的顶层，之后可以移入文件夹。原文件与副本不会自动同步；之后编辑的是知识库副本。文档菜单中的「文档信息」可查看来源、保存位置和两者关系。

## 写作和整理

Markdown 支持直接写作、文件夹整理、搜索和多文档标签。脚注和普通 HTML 文本直接在正文中编辑；公式和其他独立内容块通过对应编辑框修改。仅打开文档不会自动改写原文件。未覆盖的扩展语法及保护性回退见 [编辑范围](RELEASE-READINESS.md)。

打开知识库列表，点击顶部「知识库」左侧的四格按钮进入文档总览。每张卡片预览一个知识库中最近修改的文档。点卡片浏览文件夹，选中文档开始阅读，或用返回按钮回到刚才的文档。

不同知识库里打开的文档会留在同一排标签中。点击标签就能接着读，侧栏会跟到它所在的知识库。同名文档会在标题旁标出来源。关掉标签后，可点标签旁的「＋」，从最近打开的文档中找回它。

在还开着的标签之间查资料，回到原文可继续撤销或重做自己的编辑。正文右键剪贴会保留格式；选中一段后使用「复制给 Agent」，可以把选文和出处一起粘贴到会话里。知识库文档带上稳定文档标识，工作区预览只带该文件的来源。

按 ⌘F（Windows 和 Linux 用 Ctrl+F）查找当前正文，回车前往下一处，Shift+回车前往上一处。只记得正文的一句话时，在侧栏搜索里选「跨库正文」，点结果会打开对应的 Markdown 并定位。文档间的章节链接和 PDF 页码链接支持直接定位，可通过浏览器后退回到索引。

移动文档或文件夹后，可在提示中点「撤销移动」放回原处。

侧栏空白处右键可刷新文件列表，也可进入批量删除。选中文件夹时会包含其中的文档；确认后所选内容进入回收站。

右上角「Aa → 主题风格」可选默认、飞书、Notion 或 Obsidian。风格同时调整侧栏、当前标签、控件选中态和正文排版。字体、字号、宽度和行距可单独调整。PDF 使用独立的分页阅读器；H5 在隔离页面中预览，适合查看 Agent 生成的页面成果。PDF 不提供编辑与批注，H5 预览不等于完整网站运行环境。

## 找回修改和误删内容

文档菜单中的「历史版本」可以预览旧稿、对比差异，再决定是否恢复。恢复前会先保存当前修改。你和 Agent 同时编辑时，Typocket 会自动合并能明确区分的改动。遇到同一处的不同改法，可以比较两个版本、手动合并或另存副本。比较期间磁盘再次更新，你已填写的合并结果会保留在当前窗口。

刚输入就刷新，或保存失败后关闭页面，下次在同一浏览器打开原文档时，点「恢复草稿」可以找回尚未写入文件的修改。如果浏览器提示无法保留草稿，请先复制正文再关闭页面。

在侧栏底部「更多工具」中打开「回收站」或「备份与恢复」。旧回收文件如果缺少原路径，可以选择恢复位置。完整备份恢复成独立副本，点击「打开恢复副本」核对；页面会标明恢复副本，原库保持不变。详见 [数据与恢复](DATA-AND-RECOVERY.md)。

## 查看 Agent 改了什么

侧栏底部「更多工具 → Agent 改动」集中列出 Agent 通过 Typocket 接口做过的修改。点一条记录可以按原文排版查看改动，表格会标出变化的行。也可以切换改动前后或打开源码对照，再决定是否打开文档继续处理。通过此入口打开已有标签时，正文会核对最新版本。超出保留期或旧记录缺少可核对的快照时，详情会注明无法比较。

通过随包工具保存的修改会标记为 Agent 改动。直接改磁盘的操作不进入这份列表。需要恢复旧稿时，打开文档后在「文档操作 → 历史版本」中恢复。标记已读只改变收件箱状态，不会修改正文。

## Agent 与本地文件

DSH 可以直接使用随包的文档工具，其他支持本机 MCP 的 Agent 可以连接同一个知识库。工具按读取时的版本保存正文，遇到同时编辑会返回冲突。通过文件系统直接编辑时，权限由宿主管理。备份前请暂停外部写入。连接步骤见[插件使用说明](../plugins/reader-workspace/README.md#在其他-agent-中使用)。

## 导出与交付

文档菜单中的「导出」提供 Markdown、网页（含图片）和打印 / 导出 PDF。网页会嵌入正文图片。外部图床禁止读取或图片已失效时，导出会提示具体图片，方便你替换后重试。Markdown 源文件保留原图片地址。需要在另一台电脑上继续编辑带图文档时，选择「Markdown 和附件（ZIP）」。解压后，正文通过相对路径引用随包图片和本地链接的 PDF。普通网页链接仍指向原地址。导出是一次性文件，不会生成公开链接，也不会随后续编辑自动更新。需要给别人看时，可以直接发送导出的文件。

需要临时网址时，在文档的「更多 → 通过 Agent 分享」中选择当前文档或整个知识库，点击「复制分享提示词」并发给有托管能力的 Agent。Agent 可以通过本机工具读取选中的 Markdown、PDF、HTML 和正文引用的本地配图，制作只读快照。有文件或图片读不到时，它会告知缺项。临时托管由你使用的 Agent 提供，交付时可查看网址、有效期和关闭方式。

## 阅读与文档操作

右上角「文档操作」（三个点）提供文档信息、历史版本、原文件位置和导出；PDF 与 H5 提供打开原文件。PDF 有独立的页码和缩放控件。

排版与界面外观是当前浏览器的阅读偏好；文档图标、封面与页面布局随文档保存。触屏点击不显示悬停提示，鼠标悬停与键盘聚焦图标仍可查看提示。

## 编辑复杂文档

正文、表格、脚注和普通 HTML 文本可以直接编辑。行内公式可写成 `$x_i^2$`，独立成行的公式用 `$$` 包围。已有文档中的 `\(…\)` 和 `\[…\]` 也支持。点击公式可修改并即时预览，确认后更新正文。要展示公式源码，可以放在代码块里。文档属性独立编辑。

回收站可以按名称或原路径搜索，恢复后返回原位置。完整备份恢复为独立副本，在对应记录右侧打开。

首次安装会添加草稿知识库，可重命名或删除；删除后不会自动重建。侧栏更多工具分别提供回收站、备份与恢复入口。

## 外观

默认界面使用思源黑体（Noto Sans SC）和石墨配色。在右上角「Aa」选择浅色、柔和或深色，调整正文字体、字号、宽度和行距。「更多排版」可调整段落、表格和阅读缩放。

字体来源与许可见[第三方资产](THIRD-PARTY-ASSETS.md)。
