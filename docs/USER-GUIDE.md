# 从工作区到自己的知识库

Reader 是给个人使用的本地文档工作台。Agent 负责生成和处理文件，你负责阅读、判断、修改和整理；正文以普通文件留在本机，之后还能交给 Agent 继续工作。

## 第一次打开

在 DSH 安装插件后，进入「开始 → 阅读器」。安装包包含页面和本机服务，无需另装 Reader。首次打开创建本机知识库；再次打开沿用自己的资料。当前公开版本与本分支的区别见 [README](../README.md)。

## 查看工作成果

在 DSH 打开工作区 Markdown，使用 Reader 预览。工作区浏览记录保存曾打开的工作区文件，不混入知识库的阅读历史。记录是预览快照，原文件仍在原项目目录；再次打开原文件可以更新预览。需要定位原件时使用「在访达中显示」；Windows 对应文件资源管理器，具体宿主支持见 [平台说明](RELEASE-READINESS.md)。

想长期保留一份：打开记录，选择「收录副本」，选择知识库和文件夹。收录不会移动或修改原文件。之后编辑的是知识库副本，原文件与副本不会自动同步。文档菜单中的「文档信息」可查看来源、保存位置和两者关系。

## 写作和整理

Markdown 支持富文本写作、文件夹整理、搜索和多文档标签。编辑器不能完整保留的复杂格式会使用「原格式阅读」，需要修改时主动进入「编辑源码」。正文不会因为打开或切换阅读模式而被自动转换。

阅读排版可以调整字体、字号、宽度、行距和主题。PDF 使用独立的分页阅读器；H5 在隔离页面中预览，适合查看 Agent 生成的页面成果。PDF 不提供编辑与批注，H5 预览不等于完整网站运行环境。

## 找回修改和误删内容

文档菜单中的「历史版本」可以预览旧稿、对比差异，再决定是否恢复。恢复前会保存当前修改；如果外部编辑器或 Agent 同时改了文件，会先进入冲突处理，不直接覆盖另一份内容。

在「数据管理」里恢复删除内容或创建完整备份。旧回收文件如果缺少原路径，可以选择恢复位置。完整备份恢复成独立副本，点击「打开恢复副本」核对；页面会标明恢复副本，原库保持不变。详见 [数据与恢复](DATA-AND-RECOVERY.md)。

## 让 Agent 继续使用资料

阅读器安装后就能用。只有需要 Agent 直接检索或修改知识库时，才在「Agent 访问」中授权指定范围。工具会检查文件版本，避免把人的新修改静默覆盖。令牌属于本机授权，不应粘贴进文档或公开仓库。

## 给别人看

临时分享生成只读副本，后续编辑不会自动发布，需主动更新快照。外网链接依赖隧道服务和网络；未具备条件时可以导出文件交付。本机管理无需账号，当前不提供多人实时协作。既有服务器的可编辑示例库是部署者配置的演示能力。

## 阅读与文档操作

右上角「文档操作」（三个点）提供文档信息、历史版本、原文件位置和导出；PDF 与 H5 提供打开原文件。PDF 有独立的页码和缩放控件。

「纳入分享范围」只决定内容能否进入访客视角和分享副本，不会生成链接。知识库管理中的「分享只读副本」会先列出本次范围；原稿更新后需主动更新副本。未纳入范围的文档不显示访客编辑权限。

排版与界面外观是当前浏览器的阅读偏好；文档图标、封面与页面布局随文档保存。触屏点击不显示悬停提示，鼠标悬停与键盘聚焦图标仍可查看提示。
