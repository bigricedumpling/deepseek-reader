# Preview 发布前最终审查

## 结论与范围

候选版本为 `0.2.0-preview.1`，工作分支为 `product-v1-foundation`。本机功能与安装包验收通过，具备新一轮开源 Preview 的交付条件。它还不能据此标为所有平台均已验收的 1.0 正式版。

本轮使用独立 8197 服务、临时知识库和独立 DSH 配置。原 Reader 仓库干净；没有修改笔试题资料、重启 8090 或部署交付服务器。公开安装包已更新为 `0.2.0-preview.1`，旧包保留。

## 本轮查出的实际问题

| 问题 | 原因与处理 | 实际复验 |
| --- | --- | --- |
| 标签偏向右侧 | 标签组件添加 Teleport 后变为多根节点，父级左侧布局样式没有传入主容器；显式透传属性 | 多标签左端与正文工具栏左侧内边距一致 |
| 记录与归档含义不清 | 原功能仅隐藏浏览记录，文案却像文件归档 | 固定标题，筛选最近浏览与已隐藏；完整隐藏、找回、恢复显示流程通过 |
| 记录面板过大与窄屏拥挤 | 缺少独立尺寸与行操作布局 | 桌面最大 660px；390px 视口面板宽 374px，列表操作换行，详情与返回可操作 |
| 关闭其他标签影响当前自动保存 | 关闭任意标签都会清理当前保存计时器 | 输入后立即关闭另一标签，磁盘仍保存当前输入；测试输入随后撤回 |
| 下拉被弹窗遮挡 | Teleport 菜单仍使用普通菜单层级 | 弹窗内菜单使用 140 层级，实际显示在 120 的任务弹窗上方 |
| Escape 误关下层、Tab 丢失焦点 | 弹窗捕获菜单键盘事件，菜单关闭未返回触发位置 | Escape 只关闭菜单；Tab 从触发位置继续到记录行；右键退出返回知识库条目 |
| 详情返回丢失操作位置 | 详情与列表更换 DOM 后焦点落到页面 | 打开详情聚焦返回按钮，返回后聚焦原记录行 |
| 快速筛选显示过期结果 | 异步请求可能乱序返回 | 列表增加请求序号保护，加载与错误独立显示 |

近期已修复的标题边界、文件头属性卡片、240px 插入菜单、统一 PDF 缩放控件、触屏提示、低频工具入口和右键操作沿用前几次提交。记录与知识库继续保持不同入口；没有增加新的管理功能。
