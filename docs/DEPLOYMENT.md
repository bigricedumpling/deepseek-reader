# 服务器部署

DSH 插件用户无需部署服务器。本页适用于需要独立运行 Typocket 网站的维护者。

## 运行环境

需要 Node.js 24 或更新版本。安装依赖并构建前端：

```bash
npm ci
npm run build
```

启动时将 `DOCS_ROOT` 设为专用内容目录；该目录应位于静态站点目录之外。`PORT` 指定服务端口，`DIST_DIR` 可指定构建输出目录。通过子路径提供页面时，构建前设置对应的 `VITE_BASE`。

```bash
DOCS_ROOT=/srv/reader-content PORT=8090 node server/serve.js
```

## 访问与权限

本机使用不要求账号。远程管理需要配置 `READER_PASSWORD` 或内容目录中的私有 `.admin-password`；凭据不要写入仓库。对外提供服务时，通过反向代理配置 HTTPS，并核对服务的监听地址与访问权限。

抽屉的公开状态和锁定状态分别控制可见性与编辑权限。发布前使用访客身份检查列表、正文与附件访问，不要把整个内容目录直接交给静态文件服务器。

## 升级

升级前备份内容目录、元数据和运行配置。使用独立数据副本验证新版本后再替换程序；不要用源码仓库中的演示内容覆盖已有抽屉。

修改反向代理路径或内容目录时，需要验证原有文档链接、图片地址与权限。备份和恢复方法见 [数据与恢复](DATA-AND-RECOVERY.md)。
