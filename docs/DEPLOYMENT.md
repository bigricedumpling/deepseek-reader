# 服务器部署与既有交付兼容

插件本机使用不需要服务器部署。此页面向已有独立网站的维护者。

构建子路径时设置 `VITE_BASE`，运行服务时设置独立的 `DOCS_ROOT` 与 `DIST_DIR`。内容目录必须位于静态站点之外；不要公开整个知识库目录。远程管理需配置 `READER_PASSWORD` 或私有 `.admin-password`，本机管理不要求账号。

当前个人交付实例仍在面试使用中，以下约束持续有效：

- 不修改或迁移交付正文，不覆盖服务器用户编辑。
- 保留 `/deepseek/reader/onlyread/` 及 `/deepseek/reader/onlyread/笔试题/笔试题交付：题目一`、`题目二` 的旧链接。
- 正式交付只读，公开示例可编辑；私有内容不得出现在列表、接口或快照。
- 服务器程序升级前单独备份并验收；产品开发分支不自动部署到现有交付站点。

历史部署记录保留在 `版本更新-2026-09-29.md` 与 `archive/README-before-product-v1.md`。它们是历史记录，不是新用户安装教程。
