# Typocket 0.2.0 Preview 3

Typocket 是 DSH 中的个人文档工具，用于阅读、编辑和整理本机文件，以及预览工作区 Markdown。插件安装包包含网页和本机服务，macOS 用户安装后即可使用。

## 这一版

- 产品名称统一为 Typocket，原“知识库”层级在界面中称为“抽屉”。已有数据目录保持兼容。
- 在「更多工具 → 设置」中增加主题色预设，默认蓝色，可切换石墨、松绿、紫色和陶土。
- 统一选择、焦点、按钮和编辑器控件的主题色表现。

## 安装

从 [发布页](https://github.com/bigricedumpling/deepseek-reader/releases/tag/v0.2.0-preview.3)下载 `dsh-reader-workspace-0.2.0-preview.3.tgz`，在 DSH NEXT 的「插件 → 添加插件」中安装，再从「开始 → Typocket」进入。

已知问题和平台边界见 [支持范围](RELEASE-READINESS.md)。
