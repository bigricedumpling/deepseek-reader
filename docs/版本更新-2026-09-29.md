# 阅读器更新 2026-09-29

## 本次变化

- 调整文档图标、封面、标题及列表外观，支持 emoji 与面性图标，知识库默认展示按用途选择的实心图标；添加入口在桌面端悬停标题时显示。
- 统一弹层动效，修复标签过渡和定位样式冲突：退出项立即脱离占位，剩余标签平滑补位，关闭标签时保留其他文档。
- 增加文本颜色、高光和下划线，改进格式转换、搜索定位及长文导航。
- 图片粘贴先存为持久附件，按光标位置插入；调整图片与文字间距。
- 增加二列、三列的文字与图片排版，列内可编辑，手机端上下排列；拖拽落点只显示竖线。
- 文档使用稳定标识和保存版本检查，避免改名丢失设置、并发修改互相覆盖及中文长文件名导致历史保存失败。
- 页面设置、权限、索引迁入 SQLite；增加事务恢复、备份恢复与限定知识库权限的 Agent 接口和插件包。

### 提示块编辑修复

将提示块由不可编辑的整体展示节点改成可直接编辑的容器。可在正文内输入、换行和使用文字格式；末尾空段落再按回车或按 Cmd/Ctrl + Enter 可退出块。双击正文按普通文字选词，双击图标才打开设置。旧内容格式兼容，未修改时保留原始扩展数据；不能无损解析的特殊内容仍保留原文保护。

已实测块内输入与换行、自动保存、重开继续编辑、图标设置更新和空行退出；单元测试覆盖空块、末尾退出及相邻内容不丢失。

### 界面曲线与浏览器图标

阅读器外层界面统一使用超椭圆曲线与四档圆角尺寸，覆盖弹窗、图标和封面选择器、菜单、标签、列表、按钮、输入框和知识库入口。编辑区内部不应用这套曲线；圆形状态点与滑块继续保持圆形。支持原生连续圆角的浏览器直接绘制背景，避免叠加旧 SVG 滤镜；旧浏览器保留已有背景滤镜和圆角降级。

修复实心知识库图标被直接用作 favicon 地址的问题。实心图标和 Emoji 转为 SVG，图片图标仍使用原图片；切换知识库或更换图标时更新浏览器标签图标。

本地浏览器已核对新建弹窗、图标选择器、外观菜单、知识库弹窗和列表的实际曲线，确认编辑区提示块保持原样；切库验证 favicon 随之更新。导入检查、正式构建和历史路由回归通过。

### 浮层与提示块图标补充更新

浮层统一使用与搜索框相同的细描边，以及更淡的共享阴影；遮罩减轻并移除背景模糊。超椭圆尺寸小幅增大，编辑正文内的形状不变。公共浮层外观集中于 `src/styles/surfaces.css`，功能组件继续分别维护。

提示块左侧图标改为单击打开统一图标选择器，支持 Emoji、实心图标与图片。修改只更新图标属性，保护现有正文和打开选择器期间发生的内容变化。已验证单击、选择实心图标、自动保存和刷新后保留；构建及提示块回归通过。
