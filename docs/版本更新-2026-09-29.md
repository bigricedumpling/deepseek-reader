# 阅读器更新 2026-09-29

## 本次变化

- 调整文档图标、封面、标题及列表外观，支持 emoji 与面性图标，知识库默认展示按用途选择的实心图标；添加入口在桌面端悬停标题时显示。
- 统一弹层动效，修复标签过渡样式冲突，关闭标签时保留其他文档。
- 增加文本颜色、高光和下划线，改进格式转换、搜索定位及长文导航。
- 图片粘贴先存为持久附件，按光标位置插入；调整图片与文字间距。
- 增加二列、三列的文字与图片排版，列内可编辑，手机端上下排列；拖拽落点只显示竖线。
- 文档使用稳定标识和保存版本检查，避免改名丢失设置、并发修改互相覆盖及中文长文件名导致历史保存失败。
- 页面设置、权限、索引迁入 SQLite；增加事务恢复、备份恢复与限定知识库权限的 Agent 接口和插件包。

## 发布边界

仅发布阅读器程序。保留服务器现有正式交付知识库、示例知识库、正文、图片和公开/锁定规则；本地面试准备、课堂笔记、毕业设计、过程稿和验证库不上传。

继续兼容以下历史入口：

- `/deepseek/reader/onlyread/`
- `/deepseek/reader/onlyread/笔试题/笔试题交付：题目一`
- `/deepseek/reader/onlyread/笔试题/笔试题交付：题目二`

运行要求 Node.js 24。上线前备份旧程序和完整内容，在线上内容副本上验证迁移；阅读器使用独立运行时，不改变其他项目的 Node。

## 已知范围

Markdown 不能可靠往返时仍保留源码保护，尚未实现整套块级原文保留方案。分栏最多三列，不支持嵌套和自由调宽；鼠标拖放尚未在自动化浏览器里可靠验证，列内编辑、保存恢复及排版逻辑测试通过。Agent 插件已提供，尚未安装到用户环境。
