# 浮层与交互规范

## 层级

| 用途 | 表现 | 组件 |
| --- | --- | --- |
| 页面内的信息与分组 | 无阴影，通过留白、排版或浅底色分组 | 列表、设置分组 |
| 依附控件的菜单 | 细描边、小范围阴影，无遮罩 | 文档操作、排序、文本样式、图标选择 |
| 需要完成或取消的任务 | 页面遮罩、较深阴影，无外描边 | 回收站、备份、版本历史、内容块编辑、知识库管理 |
| 短暂提示 | 半透明深色、白字，无描边及阴影 | tooltip、目录定位提示 |

规则集中在 `src/styles/surfaces.css`。组件负责尺寸和排版，不自行定义另一套浮层层级。深浅主题使用同一层级；边界颜色从当前主题正文色计算。

## 文案

不使用中间点分隔符。信息通过分行、间距或有主语的短标签区分。按钮直接说明动作；不在常驻界面重复解释按钮功能。保留真实错误、操作结果、权限范围和可能影响数据的必要反馈。

## 数据管理

回收站按名称或原路径筛选。记录分别呈现名称、位置和删除时间。缺少原位置的旧记录显示选择位置操作。备份明确覆盖全部知识库，恢复产生独立副本，入口与对应副本同行。长内容采用单一滚动区域。

## 编辑

Markdown 文档默认直接编辑，不提供文档顶部的模式切换。脚注使用原生编辑结构，普通 HTML 文本容器支持正文内直接编辑，公式编辑提供实时预览和保存校验。未覆盖的结构必须继续补齐兼容能力，不得通过删除往返保护检查来伪造兼容。

导航、浮动控件、遮罩、任务弹窗、提示依次采用 30、90、110、120、160 的层级令牌。收起后的章节导航必须位于所有设置弹层下方。
