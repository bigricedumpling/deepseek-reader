# 浮层与交互规范

## 层级

| 用途 | 表现 | 组件 |
| --- | --- | --- |
| 页面内的信息与分组 | 无阴影，通过留白、排版或浅底色分组 | 列表、设置分组 |
| 贴在文档或图片上的短工具条 | 共用一块接近实色的半透明底，上缘内高光、短影 | 正文选区、图片操作、封面操作 |
| 依附控件的菜单 | 实底、细描边、上缘内高光和小范围阴影，无遮罩 | 文档操作、排序、文本样式、图标选择 |
| 需要完成或取消的任务 | 实底、页面遮罩、上缘内高光和较远的外阴影 | 回收站、备份、版本历史、内容块编辑 |
| 短暂提示 | 半透明深色、白字，无描边及阴影 | tooltip、目录定位提示 |

界面的连续曲线采用 `superellipse(2)`。圆角随尺寸和用途分配。菜单内按钮 7px，导航行 10px，紧凑工具条和菜单 12px，阅读设置与图标、封面选择面板 16px，文件封套外缘 18px，任务弹窗 24px。控件内外嵌套时按内边距收小内侧圆角。滑块、状态点和开关圆钮保持正圆。文档图片、公式与图表保留原有几何形状。缺少原生连续圆角支持时，标签和导航行的底色沿用共享的 SVG 圆角滤镜，其余组件保留常规圆角。

圆角由 `src/styles/shapes.css` 管理，光影和透底由 `src/styles/tokens.css` 按当前主题计算，`src/styles/surfaces.css` 分配菜单和任务弹窗层级。光线来自上方。工具条阴影距离短，菜单略高，任务弹窗更高。深色外观降低内高光亮度。标签背景负责表达选中状态，内部图标沿用整组表面。减少透明或浏览器缺少背景模糊时，工具条使用实底。

浮在封面上的知识库名称、四格入口和目录收起按钮沿用同一层窄内高光与贴面浅影。阅读设置用 1px 轮廓区分面板与页面，浅色取文字色的 8%，深色取 16%。面板内的选项以底色为主，选中项只保留贴近控件的短影。

## 文案

不使用中间点分隔符。信息通过分行、间距或有主语的短标签区分。按钮直接说明动作；不在常驻界面重复解释按钮功能。保留真实错误、操作结果、权限范围和可能影响数据的必要反馈。

## 数据管理

回收站按名称或原路径筛选。记录分别呈现名称、位置和删除时间。缺少原位置的旧记录显示选择位置操作。备份明确覆盖全部知识库，恢复产生独立副本，入口与对应副本同行。长内容采用单一滚动区域。

## 编辑

Markdown 文档默认直接编辑，不提供文档顶部的模式切换。脚注使用原生编辑结构，普通 HTML 文本容器支持正文内直接编辑，公式编辑提供实时预览和保存校验。未覆盖的结构必须继续补齐兼容能力，不得通过删除往返保护检查来伪造兼容。

导航、浮动控件、遮罩、任务弹窗、弹窗内菜单、提示依次采用 30、90、110、120、140、160 的层级令牌。收起后的章节导航必须位于所有设置弹层下方。通过 Teleport 打开的下拉和右键菜单仍须位于其所属任务弹窗之上；Escape 只关闭当前菜单，Tab 按原触发位置继续移动焦点。

正文与 DSH 预览共用标题层级。文首一级标题按主标题排版，前言后的一级标题按章节排版。连续标题之间的距离短于正文结束后开新节的距离。长标题尽量均衡换行。表格和代码块使用相同的段后留白，与用户选择的段落间距联动。脚注序号和正文首行对齐，续行对齐脚注正文。

工作区文件只在 DSH 预览中出现，不进入 Typocket 侧栏。预览页提供「保存到知识库」；收录后进入知识库，不再保留浏览记录或已读/已隐藏状态。

## 视觉密度

优先收缩现有界面，不扩充功能。普通操作菜单使用 12px 圆角、32px 左右行高和 16px 规则线性功能图标；内容图标和 Typocket 品牌图标保留各自用途。插入菜单桌面宽 228px，窄屏宽度不超过 240px，短选项下拉按触发器和文字需要定宽，不继承正文宽度。通过组间留白区分条目，禁止组件库伪元素重新绘制横线。回收站与备份分别从更多菜单进入，内部不再互设页签。

总标题开头退格保留标题类型，前方有空段落时先移除空段落；回车在标题后进入正文。文件头元数据保留序列化内容，不显示成标题前的正文卡片。

## 阅读外观与界面字体

界面默认采用石墨配色和 Noto Sans SC。「阅读设置」中的主题风格同时调整正文、侧栏底色和控件强调色；浅色、柔和、深色独立控制明暗，正文字体、字号、宽度和行距可分别设置。柔和外观使用轻微偏暖的灰白纸面。字号调整文字大小，整体缩放在「更多排版」中。

界面组件使用 `src/styles/tokens.css` 的语义颜色。主操作、选中背景、文本选区和键盘焦点各有对应变量。正文链接带下划线，错误和删除保留提示色。新选的线性图标跟随界面，既有文档的图标、上传图片和正文颜色按原样显示。

封面的配色属于文档。流动的图案在可见时播放，遵循系统减少动态效果偏好。HTML 和 PDF 导出使用相同画法生成静帧。

插件随包提供 Noto Sans SC 和 SIL OFL 许可。用户可在阅读偏好中选用本机安装的鸿蒙黑体。

## 动效与输入方式

侧栏展开时，知识库图标随侧栏渐入，收起时渐隐。排序、阅读设置和右键菜单在最终位置用 110ms 淡入、75ms 淡出。切换设置页时新选项立即就位。任务弹窗使用较长的入场时间。启用系统的减少动态效果偏好时，位置和缩放直接切换，键盘焦点仍可见。触屏直接显示条目操作入口，键盘可展开文件夹、选择图标并回到原控件。

顶栏左端是当前知识库入口。单篇文档只显示标题，多篇时用浅底和较深字色标记当前文档。侧栏收起时，左上知识库名称和开合按钮共用一块半透明底。中间标签组与右侧工具组直接显示在顶栏上。正文在顶栏下沿裁切。文档封面延伸到顶栏后方，随正文一起滚出。

侧栏的知识库列表用于快速切换。四格按钮在主阅读区打开「文档」。卡片露出真实的文档预览，前盖上缘透出纸页，名称和篇数所在区域为实底。前盖轮廓连续，浅色和深色主题都能看清边界。总览和库内路径共用一行工具栏。悬停或键盘聚焦时，前盖沿底边轻微张开，前页抬起最多 8px，中后页依次减半。名称、篇数和卡片的点击范围保持固定。触屏轻点一次直接进入。开启减少动态效果后前盖和纸页保持静止。选中文件才切换当前文档。返回上一级时恢复筛选、滚动位置与条目焦点。

从正文打开总览时，阅读面和总览各占完整宽度，选中背景在原位置淡出。返回时恢复原来的阅读位置。进入知识库时，目录就绪后一起更新路径和条目。

已打开的标签跨知识库共用一排，同名时才补来源。关闭标签时，退出项逐渐让出位置，其余标题随各自的标签一起移动。跨库切换时，文件树、当前标题与正文一起切换到最后选中的文档。切换可见标签时，选中底色朝目标的一端先伸出，中段轻轻收窄，后缘稍迟跟上。停稳后恢复 10px 的导航行圆角。连续切换从当下画面续接，目标在屏外时随标签滚入淡显。关闭当前标签时，底色跟随接替的标题补位。自动保存不能挤动标题或操作按钮。平时可在文档菜单查看保存时间，失败时在正文旁提供重试。

收起侧栏时，左上角按钮适应当前知识库名称的宽度，窄屏下超长名称显示省略号。跨库切换时，名称淡入，按钮平滑变宽或变窄，相邻标签跟随按钮移动并保持间距。顶栏弹出的菜单在目录开合时跟随触发按钮。知识库名称和右侧操作各占一列，二者留出 8px。窄侧栏优先显示名称和更多操作。文档选择器将文件名与路径分行，键盘高亮的条目保持在可视范围内。

手机文件列表和章节目录覆盖正文，选择文件或章节后回到阅读位置。顶栏为文档标题优先留位，空间紧张时将只读状态收入文档菜单。

文件拖到侧栏文件夹中间即可松手放入。稍作停留会展开下一层，移出即取消展开。工作区保存到知识库后，在新副本打开时由知识库图标确认一次，启用减少动态效果时保留静态确认。
