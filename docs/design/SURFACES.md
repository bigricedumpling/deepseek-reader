# 浮层与交互规范

## 层级

| 用途 | 表现 | 组件 |
| --- | --- | --- |
| 页面内的信息与分组 | 无阴影，通过留白、排版或浅底色分组 | 列表、设置分组 |
| 依附控件的菜单 | 细描边、小范围阴影，无遮罩 | 文档操作、排序、文本样式、图标选择 |
| 需要完成或取消的任务 | 页面遮罩、较深阴影，无外描边 | 回收站、备份、版本历史、内容块编辑、抽屉管理 |
| 短暂提示 | 半透明深色、白字，无描边及阴影 | tooltip、目录定位提示 |

规则集中在 `src/styles/surfaces.css`。组件负责尺寸和排版，不自行定义另一套浮层层级。深浅主题使用同一层级；边界颜色从当前主题正文色计算。

## 文案

不使用中间点分隔符。信息通过分行、间距或有主语的短标签区分。按钮直接说明动作；不在常驻界面重复解释按钮功能。保留真实错误、操作结果、权限范围和可能影响数据的必要反馈。

## 数据管理

回收站按名称或原路径筛选。记录分别呈现名称、位置和删除时间。缺少原位置的旧记录显示选择位置操作。备份明确覆盖全部抽屉，恢复产生独立副本，入口与对应副本同行。长内容采用单一滚动区域。

## 编辑

Markdown 文档默认直接编辑，不提供文档顶部的模式切换。脚注使用原生编辑结构，普通 HTML 文本容器支持正文内直接编辑，公式编辑提供实时预览和保存校验。未覆盖的结构必须继续补齐兼容能力，不得通过删除往返保护检查来伪造兼容。

导航、浮动控件、遮罩、任务弹窗、弹窗内菜单、提示依次采用 30、90、110、120、140、160 的层级令牌。收起后的章节导航必须位于所有设置弹层下方。通过 Teleport 打开的下拉和右键菜单仍须位于其所属任务弹窗之上；Escape 只关闭当前菜单，Tab 按原触发位置继续移动焦点。

工作区浏览记录保持固定标题，以「最近浏览」「已隐藏」筛选同一列表。隐藏与恢复只作用于记录显示，不能使用暗示文件搬迁的归档文案。详情返回后恢复对应行的键盘焦点。

## 视觉密度

优先收缩现有界面，不扩充功能。普通操作菜单使用 12px 圆角、32px 左右行高和 16px 规则线性功能图标；内容图标和 Typocket 品牌图标保留各自用途。插入菜单宽度 240px，短选项下拉按触发器和文字需要定宽，不继承正文宽度。通过组间留白区分条目，禁止组件库伪元素重新绘制横线。回收站与备份分别从更多菜单进入，内部不再互设页签。

总标题开头退格保留标题类型，前方有空段落时先移除空段落；回车在标题后进入正文。文件头元数据保留序列化内容，不显示成标题前的正文卡片。

## 主题色

主题色预设由 `src/composables/useAccent.js` 定义，默认蓝色，另有石墨、松绿、紫色和陶土。浅色与深色分别提供足够对比的强调色。组件只使用 `src/styles/tokens.css` 中的语义变量：`--c-accent` 表示强调文字与主操作，`--c-on-accent` 表示实底操作上的文字，`--c-active` 表示持续选中，`--c-selection` 表示文本选区，`--c-focus` 表示键盘焦点。悬停使用中性弱底色，不与选中混淆。

石墨预设提供灰度界面。链接在正文中保留下划线，选中主题色同时显示勾选标记，不只依赖颜色表达状态。编辑器、代码输入区和原生勾选框共用语义变量；品牌图标使用中性灰。错误和删除保留语义提示色；用户设置的正文颜色、图片、封面与语法高亮保留原意。
