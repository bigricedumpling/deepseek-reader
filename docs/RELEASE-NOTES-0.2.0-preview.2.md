# Reader 0.2.0 Preview 2

Reader 是 DSH 中的本地文档工作台，支持阅读工作区 Markdown、整理个人知识库，以及预览 PDF 和 HTML 页面。安装包自带网页与本机服务，无需另外部署 Reader 或安装 Node.js。

## 安装

下载 `dsh-reader-workspace-0.2.0-preview.2.tgz`，在 DSH NEXT 的「插件 → 添加插件」中选择安装包，再从「开始 → 阅读器」进入。
