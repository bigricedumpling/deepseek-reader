# 阅读器导航与待整理计划

本计划只在本地推进。现有公开阅读版保持单一版本；已交付的 `/onlyread/` 路径和旧中文书签必须继续打开原报告。多公开版本仅预留稳定文档身份与发布清单的扩展空间，本轮不做版本选择器或权限矩阵。

## 第一轮：供本人检查的交互稿

- [x] `/` 不再出现双入口选择：已验证管理身份进入管理工作区，访客进入公开阅读。直接访问管理地址时仍要求验证。
- [x] 左侧保留知识库列表，可按最近打开、名称、最近修改排序，常用库可以置顶；从列表进入独立的网格管理弹窗，在弹窗里检索与筛选。手机侧边列表继续使用弹窗。
- [x] 知识库、目录、文档行不常驻眼睛和锁；管理菜单说明公开状态、锁定状态及上级继承原因。访客不看到内部操作菜单。
- [x] DSH 的 Markdown 预览继续留在右侧，来源文件不自动移动或复制；本机管理者打开时写入独立的“待整理”快照，按来源去重。原文件失效或比快照更新会显示提示；远程阅读器不自动暂存工作区内容。
- [x] “待整理”可回看上次打开的完整 Markdown 与已读取的本地图片，并从快照收录为默认私有的独立文档；临时记录可以归档和恢复，均不碰源文件。DSH 预览里的“收录”仍会重新读取源文件和图片，适合需要最新内容时使用。
- [x] 正式知识库中的文档和文件夹可通过菜单复制或移动到其他知识库；选择目标目录后执行。复制出的内容默认不公开，文档资源重新归属副本；移动沿用原有权限、资源和旧地址映射。

## 后续

- 将当前公开版本记录为默认发布清单，保持老路径映射。确实出现第二类读者后再设计多版本交互。
