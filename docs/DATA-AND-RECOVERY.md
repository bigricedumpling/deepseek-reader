# 数据与恢复

## 一份完整数据包括什么

知识库目录内的正文、附件、隐藏的 `.reader` 元数据以及历史文件共同组成完整数据。只拷贝 Markdown 可以继续阅读正文，但不能保证页面设置、稳定链接、来源与版本记录完整。

工作区原文件不属于知识库备份范围。收录后的副本与原文件独立，须分别保管。

## 文档历史

文档菜单提供「历史版本」。先选择时间查看原文与当前内容的差异，再主动恢复；恢复前会保存当前未保存的修改，失败时停止恢复。选中版本进入正常编辑保存流程，仍受到版本冲突保护。最多保留 100 个版本，不能代替长期备份。

侧栏底部「更多工具 → 回收站」可查看本版删除的文档、文件夹和知识库，恢复到原位置并默认设为不公开。同名内容存在时拒绝覆盖；所属文件夹已删除时先恢复上级。页面设置和稳定文档标识一起保留。旧版回收文件缺少原路径记录，会列在「旧回收文件」中；选择目标知识库及路径后恢复，不会猜测原位置。

## 界面备份

本机打开「更多工具 → 备份与恢复」，点击「创建备份」。备份存放在知识库旁的 Reader备份 目录，按当前数据目录隔离，包含其中全部知识库，可通过文件管理器打开。

选择「恢复副本」会生成一个独立目录，不替换当前知识库。恢复后可点击「打开恢复副本」，在独立的本机阅读器中核对。页面会标明「恢复副本」，原库不会被替换。此功能不是云备份，同一磁盘损坏仍可能丢失两份，重要备份应另外保管。

备份期间应暂停外部编辑器或 Agent 直接写入文件；Reader 内的写操作会被备份锁阻止，文件系统外部写入不受这把锁控制。

备份不会包含登录会话与 Agent 授权。遇到符号链接会停止并提示，避免把外部文件误打进备份。

## 完整备份与恢复（开发者操作）

现有命令在知识库之外生成新目录；恢复只允许写入不存在的新目录，避免覆盖原库。

```bash
DOCS_ROOT=/absolute/knowledge node scripts/backup-workspace.mjs /absolute/new-backup
node scripts/restore-workspace.mjs /absolute/new-backup /absolute/new-restored-library
```

以上环境变量写法用于 macOS/Linux shell；Windows PowerShell 使用 `$env:DOCS_ROOT='C:\path\knowledge'` 后再执行备份命令。

备份包括正文、附件、页面设置、来源与历史索引，不包含 Agent 凭据或登录会话。恢复后需重新授权 Agent。备份可能含私有资料，不要上传公开仓库。

恢复到新目录后先检查文档、附件与设置，再选择是否切换插件的数据目录；保留原库，不能靠覆盖目录完成迁移。界面可创建和恢复本机生成的备份；跨机器导入备份仍需使用开发者命令；自动替换当前插件数据目录暂不支持。
