# Typocket 0.2.0 Preview 4

Typocket 是 DSH 中的个人文档工具，用于阅读、编辑和整理本机文件，以及预览工作区 Markdown。插件安装包包含网页和本机服务，macOS 用户安装后即可使用。

## 这一版

- 新安装的插件默认使用石墨主题色和鸿蒙黑体界面字体；已有用户在浏览器中选择过的外观继续保留。
- 「更多工具 → 设置」中可切换界面字体，选择不影响文档正文的字体与排版。
- 鸿蒙黑体随插件分发，保留华为原版字体文件和独立许可；在设置中可查看版权声明及许可。

## 安装

从 [发布页](https://github.com/bigricedumpling/deepseek-reader/releases/tag/v0.2.0-preview.4)下载 `dsh-reader-workspace-0.2.0-preview.4.tgz`，在 DSH NEXT 的「插件 → 添加插件」中安装，再从「开始 → Typocket」进入。

已知问题和平台边界见 [支持范围](RELEASE-READINESS.md)。
